# Grok Go — Онлайн Го с Порталами

Классический Го + полностью оригинальный режим **Portal Go**.

## Возможности

- Создание сессий и подключение в реальном времени (WebSocket)
- Два режима:
  - **Классический Го**
  - **Portal Go** — новый режим с механикой порталов (не существует в популярных вариантах)
- Доски 9×9, 13×13 и 19×19
- Полноценная реализация правил (захваты, Ко, подсчёт по площади)
- Красивая доска на Canvas с поддержкой тача

## Запуск

```bash
# 1. Активируйте виртуальное окружение (создано автоматически)
source .venv/bin/activate

# 2. Запустите сервер
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте в браузере: http://localhost:8000

## Оригинальный режим: Portal Go

На доске размещены 4 портала.

Камни, стоящие рядом с одним и тем же порталом, считаются **соединёнными** между собой.  
Группы могут захватывать и иметь дамэ через порталы, даже если находятся на противоположных концах доски.

Это создаёт совершенно новую тактику и стратегические приоритеты.

## Архитектура

- `app/go_engine.py` — чистая реализация правил Го (с поддержкой порталов)
- `app/game_manager.py` — управление сессиями и WebSocket-комнатами
- `app/main.py` — FastAPI + REST + WebSocket
- `static/index.html` — полностью автономный фронтенд (Tailwind + Canvas)

Всё работает без внешних зависимостей на клиенте.

## Ограничения текущей среды

- Сервер запускается только из Python (uvicorn)
- Git и Node.js в текущем WSL-окружении ограничены
- Данные хранятся только в памяти процесса
